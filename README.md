# Niraj Malla - Interactive AI Engineer Resume Website

A modern, responsive, and interactive developer/AI-engineer resume website for **Niraj Malla**, inspired by the reference design of [Arunraj S's Portfolio](https://arunraj-portfolio-v1.vercel.app/).

## 🚀 Key Features

- **Dark & Light Mode**: Seamless theme switching with persistent state and obsidian/charcoal dark theme with glowing red accents.
- **Modern Typography & Glassmorphism**: Built with `Outfit`, `Plus Jakarta Sans`, and `JetBrains Mono` with responsive glassmorphic headers and animated cards.
- **Authentic CV Data**:
  - Full details of all 5 projects (AI Video Interview Assessment, Smart Toll Plaza System, Bulldozer Price Prediction, Customer Churn, and Pingen QR).
  - Categorized skills without fake percentage bars.
  - Engineering Experience timeline, Education, and AI/ML Research focus.
  - Achievements (OpenAI Codex Hackathon Top 30%) and Certifications.
- **ATS-Compliant Printable Resume**:
  - Built-in preview modal with single-column ATS semantic hierarchy.
  - One-click "Print / Save PDF" feature using `@media print` CSS engine.
- **Direct Contact**: Interactive message form, email/phone copy-to-clipboard, and direct social links.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + `@tailwindcss/vite`
- **Icons**: Lucide React + custom SVG brand icons
- **Build Tool**: Vite 6

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open `http://localhost:3000` or the port shown in your terminal.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview the Production Build
```bash
npm run preview
```
